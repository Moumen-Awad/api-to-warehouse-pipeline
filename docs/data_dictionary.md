| Column | Type | Description |
| --- | --- | --- |
| `coin_id` | text | Unique CoinGecko identifier for the coin |
| `name` | text | Human-readable coin name |
| `metric_date` | date | Day the metrics were aggregated for |
| `avg_price_usd` | numeric | Average price in USD for that day |
| `market_cap_usd` | numeric | Market capitalization in USD |
| `avg_price_change_pct_24h` | numeric | Average 24h price change percentage |
